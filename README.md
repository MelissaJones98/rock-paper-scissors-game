# Rock Paper Scissors

A simple browser-based Rock Paper Scissors game built with HTML, CSS and vanilla JavaScript.

## How to play

1. Open `index.html` in your web browser.
2. Click **Rock**, **Paper** or **Scissors**.
3. The computer picks a hand at random, and the result appears below the buttons.

### Rules

- 🪨 Rock beats ✂️ Scissors
- 📜 Paper beats 🪨 Rock
- ✂️ Scissors beats 📜 Paper
- Picking the same hand is a tie

## Project structure

| File         | Purpose                                                                                                                              |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| `index.html` | Page layout: the title, the three choice buttons and the result message                                                              |
| `styles.css` | Styling: the [Silkscreen](https://fonts.google.com/specimen/Silkscreen) pixel font, colours, button hover effects and the result box |
| `script.js`  | Game logic: listens for button clicks, picks the computer's hand and decides the winner                                              |

## Built with

- HTML5
- CSS3
- JavaScript (no frameworks or build tools)
- [Google Fonts](https://fonts.google.com/) for the Silkscreen font
